ระบบบริหารจัดการ : ระบบร้องเรียน

เทศบาลเมืองวารินชำราบ จังหวัดอุบลราชธานี

📝 Public

หน้ารับคำร้องเรียน

สำหรับประชาชนทั่วไปใช้งานแจ้งเรื่องร้องเรียนเข้ามายังระบบ
🔍 Tracking

หน้าติดตามคำร้องเรียน

ตรวจสอบสถานะการดำเนินงานและประเมินความพึงพอใจของประชาชน
📊 Analytics

หน้า Dashboard

ภาพรวมสถิติกราฟข้อมูลและแผนที่แสดงพิกัดจุดเกิดเหตุร้องเรียน
🏷️ Assign

ระบบมอบหมายงาน

ตรวจสอบตำแหน่งบนแผนที่และติด Tag กอง/ฝ่ายรับผิดชอบ
🛠️ Staff Only

หน้าจัดการปิดคำร้องเรียน

สำหรับเจ้าหน้าที่อัปเดตผลการดำเนินงาน อัพโหลดรูป และปิดงาน
📋 Report

หน้ารายงานสรุปผล

ค้นหากรองข้อมูลย้อนหลัง พร้อมส่งออกเป็นไฟล์ Excel และ PDF
⭐ Feedback

หน้ารายงานความพึงพอใจ

สรุปคะแนนดาว กราฟวงกลมร้อยละ และคำแนะนำจากประชาชน
🗑️ Admin

หน้าลบข้อมูลเรื่องร้องเรียน

สำหรับผู้ดูแลระบบในการจัดการลบรายการคำร้องที่ไม่ต้องการ
